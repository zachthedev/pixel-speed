# Contributing

- Code, tests, and the gate: [docs/contributing.md](docs/contributing.md) and
  [docs/build-and-run.md](docs/build-and-run.md).
- Translations: edit on [Weblate](https://hosted.weblate.org/projects/pixel-speed/), never by
  pull request against the locale files.
- Bugs and ideas: the [issue forms](https://github.com/zachthedev/pixel-speed/issues/new/choose).
  A bug report with the diagnostics file from Help > Report a problem gets fixed fastest.
- Security: [SECURITY.md](SECURITY.md).
